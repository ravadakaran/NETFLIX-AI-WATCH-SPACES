================================================================================
          NETFLIX AI WATCH SPACES --- COMPLETE EXECUTION & RUN GUIDE
================================================================================

This document provides exact, step-by-step instructions to run, test, and
verify both the Spring Boot backend and React/Vite frontend.

--------------------------------------------------------------------------------
1. SYSTEM PREREQUISITES
--------------------------------------------------------------------------------
- Java: JDK 11 or higher (Check: `java -version`)
- Maven: 3.6 or higher (Check: `mvn -version`)
- Node.js: v18.0 or higher (Check: `node -v`)
- npm: v9.0 or higher (Check: `npm -v`)
- Git (Check: `git --version`)
- OS: Windows / macOS / Linux

--------------------------------------------------------------------------------
2. PROJECT TOPOLOGY & PORTS
--------------------------------------------------------------------------------
- Backend Server:   http://localhost:8081
- WebSocket URL:    ws://localhost:8081/ws/watch-spaces/{id}?token={jwt}
- Frontend Client:  http://localhost:5173
- Database:         Neon Cloud Serverless PostgreSQL (pre-configured)

--------------------------------------------------------------------------------
3. ENVIRONMENT SETUP
--------------------------------------------------------------------------------
Check that a `.env` file exists in the project root (d:\projects\Netflix\.env).
If starting fresh on a new machine, copy `.env.example` to `.env`:

  Windows (PowerShell):
    Copy-Item .env.example .env

  macOS / Linux:
    cp .env.example .env

The default settings connect directly to the managed cloud database.
Key properties:
  SERVER_PORT=8081
  CLIENT_URL=http://localhost:5173
  CORS_ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000,http://127.0.0.1:5173
  JWT_SECRET=404E635266556A586E3272357538782F413F4428472B4B6250645367566B5970

4. STARTING THE BACKEND (Spring Boot)
--------------------------------------------------------------------------------
Open a terminal (Terminal 1) and navigate to the backend directory:

  cd d:\projects\Netflix\backend

Step 4.1: Run Backend Tests (Optional verification)
  mvn test

Step 4.2: Start the Spring Boot Application
  mvn spring-boot:run

When ready, the logs will display:
  [main] INFO  ... - Started WatchSpacesApplication in X.XXX seconds
  The backend is now live on http://localhost:8081

Data Auto-Seeding:

- 3 Personas: admin@example.com, host@example.com, viewer@example.com (Password: password)
- 5 Titles: Cyberpunk 2099, Cosmos Deep, Shadow Protocol, Neon Horizon, Echoes of the Void

--------------------------------------------------------------------------------
Open a separate terminal (Terminal 2) and navigate to the frontend directory:

--------------------------------------------------------------------------------
9. TROUBLESHOOTING & FAQS
--------------------------------------------------------------------------------
Q: Port 8081 is already in use.
A: Either stop the running process on port 8081, or change `SERVER_PORT=8082` in `.env`
   and update `vite.config.ts` proxy target if proxying.

Q: PostgreSQL connection error on startup.
A: Ensure your internet connection allows outbound SSL to Neon cloud.
   Connection string uses `sslmode=require`.

Q: WebSocket connection fails (`room.sync.pong` not received).
A: Confirm the backend is running on port 8081 and that your browser is allowing
   WebSocket connections to `ws://localhost:8081`.

Q: "Session expired" toast message appears.
A: Your JWT access token expired and the refresh token was rotated or cleared.
   Simply sign in again with any of the demo accounts above.
